# Bambang Istijab — 3D Interactive Portfolio

An interactive 3D portfolio website that presents my profile, projects, skills, and experience through a virtual desktop environment.

Instead of using a conventional portfolio layout, this project creates an immersive workspace where visitors can explore the environment and interact with different objects on the virtual computer.

## 🌐 Live Demo

[Visit My Portfolio](https://portfolio-bambangistijab.netlify.app/)

## ✨ Features

- 🖥️ Interactive 3D desktop environment
- 🖱️ First-person camera and mouse interaction
- 💻 Interactive computer interface
- 🎮 Built-in virtual OS experience
- 🎵 Interactive audio environment
- ☕ Animated coffee steam
- 🖼️ 3D models and environment assets
- 🎨 Custom shaders and visual effects
- 📱 Responsive interface
- ⚡ Webpack production build
- 🎯 Interactive objects and hitboxes
